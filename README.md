# GRAAL Utils

A collection of software utils and guides.

## Subfolders and projects

- **`bitbucket_to_github_migration/`**: Scripts to list repositories and migrate projects from Bitbucket to GitHub.
- **`conventions_for_writing_code/`**: Coding conventions and style guidelines used across GRAAL repositories.
- **`doxygen_guide/`**: Quick instructions for installing Doxygen and generating project documentation.
- **`graal_website/`**: Notes and operational info for managing the GRAAL Joomla website.
- **`latex_documentation_template/`**: Template and assets for writing technical documentation in LaTeX.
- **`latex_thesis_template/`**: Thesis-oriented LaTeX template based on the `ortotesi` class.
- **`panda_robots_setup/`**: Network and access setup notes for the Franka Panda robots.
- **`qtcreator_ros2_setup/`**: Guide to configure QtCreator for ROS2 development.
- **`scripts/`**: Utility shell scripts for dependency setup and common repository maintenance commands.
